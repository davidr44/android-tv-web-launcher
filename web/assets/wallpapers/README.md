# Launcher wallpapers

The fifteen entries in `SOURCES.json` each have a background JPEG, a thumbnail and a small blurred panel backdrop. Four registered material JPEGs per image live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages and authors are in [photo credits](../../../docs/photo-credits.md). The images were generated by CleanFrame; Início only shrinks the materials (`tools/shrink_materials.py`). Full-size originals remain outside the repository.
